# Block-game

모바일 브라우저에서 바로 실행되는 블럭(테트리스 스타일) 게임입니다. `index.html` 하나로 동작하며 설치할 것이 없습니다.

## 실행 방법
- `index.html` 파일을 휴대폰 브라우저로 열거나, GitHub Pages 등으로 호스팅해서 접속하세요.

## 조작법
| 동작 | 터치 | 버튼 | 키보드 |
|---|---|---|---|
| 이동 | 좌우 스와이프 | ◀ ▶ | ← → |
| 회전 | 화면 탭 | ⟳ | ↑ / X |
| 빠르게 내리기 | 아래로 스와이프 | ▼ | ↓ |
| 바로 떨어뜨리기 | 아래로 빠르게 튕기기 | ⤓ | Space |
| 보관 | 위로 스와이프 / 보관 칸 탭 | | C / Shift |
| 일시정지 | | ⏸ | P / Esc |

게임판은 가로 20칸 × 세로 20칸입니다. 휴대폰처럼 화면이 좁으면 판이 떨어지는 블럭을 따라 좌우로 움직입니다.

10줄마다 레벨이 오르고 속도가 빨라집니다. 최고 점수는 기기에 저장됩니다.
